Task ID: R18-T030 PR #82 • Open / Review Playwright • Browser Regression Check

PR #82: Add Audio Transcript UI Regression Check

View PR #82 on GitHub →

📝 Description of Code Modifications

Implemented an automated Playwright browser regression check in tests/course/r18-t030.mjs verifying audio sources, fallback links, custom controls, and time display. Added a temporary served mutation fixture verifying that removing transcript click bindings triggers expected assertion failures when controls remain at “Show transcript” and layout height stays at 0px. Documented run instructions and saved baseline, inputs, and results under work/R18-T030/.

💡 Technical Rationale

Manual audio UI verification is non-deterministic across varying device hardware and audio drivers. By stubbing audio playback state and launching an isolated Python loopback static server with automated browser context teardown, the test suite guarantees deterministic, headless regression coverage across continuous integration pipelines without modifying baseline application source code.

Task ID: R18-T029 PR #81 • Open / Review Accessibility & Responsive Layout

PR #81: Test Heroes Reduced Motion, Keyboard Focus & Responsive Viewports

View PR #81 on GitHub →

📝 Description of Code Modifications

Enhanced javascript/oojs/json/heroes.html and style.css by implementing an accessible keyboard skip-link navigating directly to the main heroes content region with high-contrast visible focus styling. Refactored the rigid 800px content container to dynamically adapt across narrow viewports (375px mobile through 1280px desktop). Authored automated Playwright regression tests in tests/course/r18-t029.mjs verifying computed focus styles and geometry with reduced motion enabled.

💡 Technical Rationale

Fixed-width layouts violate WCAG 2.1 Reflow criteria (Success Criterion 1.4.10) causing horizontal scrolling on mobile viewports. Adding keyboard skip-links and visible focus rings satisfies WCAG 2.4.1 (Bypass Blocks) and 2.4.7 (Focus Visible), enabling motor-impaired and keyboard-only users to navigate directly to the primary data view without repetitive tab traversal.

Task ID: R18-T028 PR #80 • Open / Review Security & Cross-Browser Testing

PR #80: Add Safe Text-Rendering Regression Companion

View PR #80 on GitHub →

📝 Description of Code Modifications

Added an isolated text-rendering companion in tools-testing/cross-browser-testing/automation/. Enforced strict plain-text contracts utilizing textContent for user-submitted form strings while preserving preexisting arrow-function outputs. Authored Playwright regression suite in tests/course/r18-t028.mjs verifying injected-element safety, event delegation handlers, computed layout integrity, and zero page console errors.

💡 Technical Rationale

Direct assignment of dynamic user strings to innerHTML introduces severe Cross-Site Scripting (XSS) vulnerabilities. Enforcing textContent ensures input strings are treated strictly as character data rather than parsed markup, mitigating injection attacks while automated regression testing validates that cross-browser automation pipelines remain completely stable.
